Sample media
============

Every picture the documentation demos put on screen -- the faces in PlAvatar,
the plates in PlGallery, the wallpaper behind PlMockup, the mark in PlAppLogo.
None of it is part of the library. It is stand-in content, the way a caller's
own photographs would be.

(Plain text rather than Markdown on purpose: VitePress routes a Markdown file
under `public/` as a page of the site, and this is a notice, not a page.)

Nobody in `avatars/` is real. They are generated people with generated names,
and the name a demo prints is the one the file carries. Do not pair one of these
faces with the name of a real person, living or dead: a portrait under a real
name is a claim about that person's likeness, and none of these pictures can
make it. The demos that name a historical figure -- PlHoverCard, for one --
deliberately show no face.

The places are not real either. A caption says what the picture shows and never
where it was taken.


Layout
------

    avatars/         Faces, cut out, so the avatar's own fill shows behind.
                     256x256, with an alpha channel.
    photos/          Photographs for galleries, cards, media and previews.
                     800px on the long edge.
    illustrations/   Drawn artwork for empty states and device wallpaper.
                     800px on the long edge.
    marks/           Product marks for PlAppLogo and rows of customer logos.
                     128x128, with an alpha channel.

A file keeps the subject its source was named after, so any picture here can be
traced back to the file it was derived from.


How they were derived
---------------------

The originals are 1024-1536px PNG and JPEG, and several megabytes each. A
documentation site wants neither, so each one was resized and re-encoded to
WebP once, with sips, ffmpeg and cwebp:

    # A face: crop to head and shoulders, keeping the transparent background.
    ffmpeg -i <source>.png -vf 'crop=880:880:72:20,scale=256:256:flags=lanczos' face.png
    cwebp -q 82 -alpha_q 100 face.png -o avatars/<name>.webp

    # A photograph or an illustration.
    sips -Z 800 <source>.jpg --out plate.jpg
    cwebp -q 76 plate.jpg -o photos/<name>.webp

    # A mark, which keeps its alpha.
    sips -z 128 128 <source>.png --out mark.png
    cwebp -q 88 -alpha_q 100 mark.png -o marks/<name>.webp

Add a picture the same way rather than copying an original in: a 3 MB plate
behind a 40 KB preview is the whole page's load time.
