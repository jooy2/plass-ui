모든 컴포넌트 ​

지금까지 공개된 전부입니다. 각 카드 안의 미리 보기는 실제로 돌아가고 있는 컴포넌트 자체입니다.

아래 갤러리는 React 빌드입니다. 카드 하나하나가 실제로 동작하는 미리 보기이고 133개나 되는데, Flutter 프레임은 하나가 곧 엔진 하나이기 때문입니다. 목록은 어느 쪽이든 같습니다. PlFlex, PlPortal, PlVisuallyHidden 세 개만 React 전용이고, 각 페이지가 어느 쪽을 다루는지 밝힙니다.

  • 한 화면에 모아 놓은 모습은 홈에서 볼 수 있습니다.
  • 공통 prop이 뜻하는 것은 Prop 규칙에 있습니다.
  • 표면과 색, 모션이 왜 이렇게 생겼는지는 디자인 언어에 있습니다.
